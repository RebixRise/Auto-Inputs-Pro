## 🔍 نظرة عامة

**Auto-Inputs-Pro** هو امتداد متصفح متطور يقوم بملء حقول النماذج تلقائيًا باستخدام الذكاء الاصطناعي من Google Gemini (مع دعم قادم لنماذج ذكاء اصطناعي إضافية). يقوم هذا الامتداد بتحليل سياق الصفحة وعناوين الحقول بذكاء لتوليد معلومات مناسبة وواقعية بناءً على السياق واللغة المستخدمة في صفحة الويب.

تم تصميم الامتداد لتوفير الوقت عند اختبار النماذج أو إنشاء الحسابات أو ملء المعلومات المتكررة، مع توفير استجابات مناسبة سياقياً ومنطقية لكل حقل.

---

## ✨ المميزات الرئيسية

- **اكتشاف النماذج بذكاء**: يحدد النماذج وحقولها تلقائياً في أي صفحة ويب
- **فهم السياق**: يحلل المحتوى المحيط لتوفير مدخلات مناسبة للحقول
- **خيارات متعددة للملء**:
  - ملء جميع حقول النماذج في الصفحة دفعة واحدة
  - ملء نموذج محدد عند النقر على أي حقل داخله
  - ملء حقل واحد محدد عند الطلب
- **دعم نماذج ذكاء اصطناعي متعددة**: يدعم حالياً Google Gemini AI، مع دعم قادم لـ OpenAI و Claude AI
- **تقديم النماذج تلقائياً**: إمكانية تقديم النماذج تلقائياً بعد الملء (قابل للتخصيص)
- **تصدير/استيراد الإعدادات**: نسخ احتياطي أو نقل الإعدادات بين الأجهزة
- **تأخير مخصص**: تكوين التأخير بين إكمال كل حقل لتجنب حدود معدل الاستخدام
- **دعم أنواع الحقول المختلفة**:
  - حقول النص ومناطق النص
  - حقول البريد الإلكتروني
  - حقول كلمات المرور
  - القوائم المنسدلة
  - مربعات الاختيار وأزرار الاختيار
  - محددات التاريخ
  - حقول الأرقام
- **دعم متعدد اللغات**: ينشئ محتوى بلغة موقع الويب
- **ربط ذكي للنماذج**: يحدد بذكاء أي الحقول تنتمي لأي نماذج
- **واجهة مستخدم سهلة**: لوحة منبثقة بديهية للإعدادات
- **إشعارات داخل الصفحة**: إشعارات قابلة للتخصيص مدمجة في صفحة الويب

## 📥 التثبيت

### من متجر المتصفح
1. قم بزيارة متجر الامتدادات لمتصفحك:
   - [متجر Chrome](https://chrome.google.com/webstore) (قريباً)
   - [إضافات Firefox](https://addons.mozilla.org/firefox/) (قريباً)
   - [إضافات Edge](https://microsoftedge.microsoft.com/addons/) (قريباً)
2. ابحث عن "Auto-Inputs-Pro"
3. انقر على "إضافة إلى [المتصفح]"

### التثبيت اليدوي (وضع المطور)
1. قم بتنزيل أحدث إصدار من [مستودع GitHub](https://github.com/RebixRise/Auto-Inputs-Pro/releases)
2. استخرج ملف ZIP إلى مجلد على جهاز الكمبيوتر الخاص بك
3. افتح صفحة إدارة الامتدادات في متصفحك:
   - Chrome: `chrome://extensions/`
   - Firefox: `about:addons`
   - Edge: `edge://extensions/`
4. قم بتمكين "وضع المطور"
5. انقر على "تحميل مفكوك الضغط" (Chrome/Edge) أو "تحميل إضافة مؤقتة" (Firefox)
6. حدد المجلد الذي يحتوي على ملفات الامتداد المستخرجة

## 🚀 دليل الاستخدام

### الإعداد الأولي
1. قم بتثبيت الامتداد
2. انقر على أيقونة الامتداد في شريط أدوات المتصفح
3. اختر نموذج الذكاء الاصطناعي المفضل لديك (حالياً Gemini AI)
4. أدخل مفتاح API الخاص بك واضغط على "حفظ"
5. قم بتخصيص الإعدادات الإضافية وفقاً لتفضيلاتك:
   - تفعيل/تعطيل تقديم النماذج تلقائياً
   - تفعيل/تعطيل الإشعارات
   - ضبط تأخير ملء الحقول

### استخدام الامتداد

#### الطريقة الأولى: قائمة السياق
1. انقر بزر الماوس الأيمن على أي جزء من صفحة الويب للوصول إلى قائمة السياق
2. اختر أحد الخيارات التالية:
   - **ملء جميع الحقول**: يكمل جميع حقول النماذج في الصفحة
   - **ملء هذا النموذج**: يكمل فقط النموذج الذي يحتوي على الحقل الذي نقرت عليه بزر الماوس الأيمن
   - **ملء هذا الحقل**: يكمل فقط الحقل المحدد الذي نقرت عليه بزر الماوس الأيمن

#### الطريقة الثانية: نافذة الامتداد المنبثقة
1. انقر على أيقونة الامتداد في شريط أدوات المتصفح
2. استخدم الأزرار المتوفرة لـ:
   - ملء جميع الحقول في الصفحة الحالية
   - تكوين إعداداتك
   - عرض إحصائيات الاستخدام

### نسخ احتياطي للإعدادات
- **تصدير الإعدادات**: انقر على زر "تصدير الإعدادات" لحفظ ملف JSON بإعداداتك
- **استيراد الإعدادات**: انقر على زر "استيراد الإعدادات" واختر ملف إعدادات تم تصديره سابقاً

## 🔧 البنية التقنية

تم بناء Auto-Inputs-Pro كامتداد متصفح باستخدام واجهة برمجة تطبيقات WebExtensions، مما يجعله متوافقاً مع معظم المتصفحات الحديثة.

### هيكل المكونات

- **ملف التعريف (manifest.json)**: يحدد بيانات التعريف بالامتداد والأذونات وعلاقات المكونات
- **نص البرمجة الخلفي (js/background.js)**: يتعامل مع إنشاء قائمة السياق والعمليات الخلفية والاتصال بين المكونات
- **نص برمجة المحتوى (js/content.js)**: يتفاعل مع DOM لصفحة الويب لتحديد وملء حقول النماذج
- **واجهة المستخدم المنبثقة (popup.html, js/popup.js, css/popup.css)**: توفر واجهة المستخدم للتكوين والإجراءات اليدوية
- **المكتبات الداعمة (js/lib/)**: تحتوي على مكتبات من جهات خارجية لتعزيز الوظائف

### التقنيات الرئيسية

- **جافا سكريبت (ES6+)**: لغة البرمجة الأساسية
- **واجهة برمجة امتدادات Chrome**: للتكامل مع المتصفح
- **واجهة برمجة Fetch**: للاتصال بخدمات الذكاء الاصطناعي
- **واجهة برمجة التخزين المحلي**: لحفظ تفضيلات المستخدم
- **التلاعب بـ DOM**: لاكتشاف وإكمال حقول النماذج
- **Chart.js**: لتصور إحصائيات الاستخدام

### خوارزمية اكتشاف حقول النماذج

يستخدم الامتداد خوارزمية متطورة لاكتشاف حقول النماذج:
1. تحديد جميع عناصر الإدخال والاختيار ومناطق النص
2. ربط الحقول بنماذجها المقابلة
3. تحليل سمات الحقل (النوع، الاسم، المعرف، النص التلميحي)
4. فحص عقد النص القريبة والتسميات
5. تحديد الغرض من كل حقل بناءً على القرائن السياقية

### عملية تكامل الذكاء الاصطناعي

1. جمع معلومات حقول النماذج (أنواع الحقول، التسميات، القيم الموجودة)
2. جمع سياق الصفحة (عنوان URL، العنوان، النص المحيط)
3. بناء استعلام لخدمة الذكاء الاصطناعي
4. إرسال الطلب إلى نموذج الذكاء الاصطناعي المحدد
5. معالجة استجابة الذكاء الاصطناعي
6. ربط المحتوى المنشأ بحقول النماذج المناسبة
7. تطبيق المحتوى بتنسيق مناسب لكل نوع حقل

## 🔒 الأمان والخصوصية

### معالجة البيانات
- يتم تخزين مفتاح API الخاص بك محلياً في تخزين المتصفح الآمن
- لا تتم مشاركة مفاتيح API مع أي طرف ثالث
- يتم إرسال بيانات السياق (مثل تسميات الحقول) فقط إلى خدمة الذكاء الاصطناعي المحددة للمساعدة في توليد معلومات مناسبة
- لا يتم جمع أو تخزين أي معلومات شخصية

### شرح الأذونات

| الإذن | الاستخدام |
|------------|-------|
| `storage` | يخزن إعداداتك ومفاتيح API محلياً |
| `contextMenus` | يوفر خيارات قائمة النقر بزر الماوس الأيمن |
| `activeTab` | يسمح للامتداد بالتفاعل مع صفحة الويب الحالية |
| `scripting` | يمكّن اكتشاف وملء حقول النماذج |
| `notifications` | يعرض تحديثات الحالة |
| `<all_urls>` | يسمح للامتداد بالعمل على أي موقع ويب |

## 💻 التطوير

1. استنساخ المستودع:
   ```

├── .gitignore             # ملف تجاهل Git

├── README.ar.md           # التوثيق باللغة العربية
├── LICENSE                # ملف الترخيص

│   └── icons/             # أيقونات الامتداد
├── css/                   # أوراق الأنماط
│   └── popup.css          # أنماط واجهة المستخدم المنبثقة
└── js/                    # ملفات جافا سكريبت
    ├── background.js      # عامل خدمة الخلفية
    ├── content.js         # نص البرمجة للتفاعل مع صفحة الويب
    ├── popup.js           # وظائف واجهة المستخدم المنبثقة
    ├── translations.js    # سلاسل الترجمة
```

## ❓ استكشاف الأخطاء وإصلاحها

### المشكلات الشائعة

#### مشكلات مفتاح API
- **خطأ: مفتاح API غير صالح**: تحقق من صحة مفتاح API الخاص بك وأنه لم تنته صلاحيته
- **خطأ: تجاوز حصة API**: قد يكون قد تم الوصول إلى حد استخدام API الخاص بك؛ تحقق من لوحة معلومات خدمة الذكاء الاصطناعي

#### مشكلات اكتشاف الحقول
- **بعض الحقول لم يتم اكتشافها**: حاول ضبط إعداد دقة الاكتشاف إلى "مرتفع"
- **معلومات خاطئة في الحقول**: قد يحتاج الذكاء الاصطناعي إلى المزيد من السياق؛ حاول ملء نموذج محدد أو حقل محدد

#### الامتداد لا يعمل
- **الامتداد لا يظهر**: تأكد من تمكين الامتداد في متصفحك
- **قائمة السياق مفقودة**: حاول إعادة تشغيل متصفحك
- **لا استجابة عند النقر على الخيارات**: تحقق من وحدة تحكم المتصفح بحثاً عن الأخطاء

### الحصول على الدعم

إذا واجهت مشكلات لم تتم تغطيتها هنا، يرجى:
1. التحقق من [مشكلات GitHub](https://github.com/RebixRise/Auto-Inputs-Pro/issues) لمشكلات مماثلة
2. إنشاء مشكلة جديدة مع معلومات مفصلة إذا لم تكن مشكلتك مدرجة
3. تضمين إصدار المتصفح وإصدار الامتداد وخطوات إعادة إنتاج المشكلة
