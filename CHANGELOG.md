# Changelog

All notable changes to the Auto-Inputs-Pro extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-05-30

### Added
- Initial release of Auto-Inputs-Pro
- Intelligent form field detection and auto-completion
- Context menu with multiple filling options (all inputs, single form, single input)
- Support for Gemini AI
- Custom delay settings between field completions
- Language detection based on page content
- Dark mode support for extension UI
- Import/export settings functionality
- Automatic form submission option
- Smart form association algorithm
- Statistics tracking for filled forms
- On-page notifications
- Multi-language UI support (English and Arabic)

### Security
- Secure local storage for API keys
- Strict content security policy implementation
- No collection of personal data

## [Unreleased]

### Planned Additions
- Support for additional AI models (OpenAI, Claude AI)
- Custom response templates for specific websites
- Multiple profiles for different use cases
- Improved field relationship detection
- Advanced site support for popular platforms
- Enhanced statistics and analytics
